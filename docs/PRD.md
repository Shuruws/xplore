# xplore

有意思的项目，慢慢收集。

## 目的
每天发现 1–2 个值得看演示、读资料或动手尝试的项目。重点为 HCI、AI 与人、实体计算和认知交互；经典项目同样可收录。

## 核心体验
- 打开画廊，几秒内看懂项目亮点。
- 按主题筛选、搜索、收藏；详情只写亮点、机制、局限和原始链接。
- 每项标注团队、项目年份、来源核验日期；收录时间不冒充项目发布时间。
- 订阅邮件＋RSS；邮件先确认、随时退订，不向未确认的邮箱发送精选。

## 本次 Demo
- A 图文卡片、B 瀑布画廊、C 紧凑目录，用户选一种。
- 8 项真实内容；暖黑、米白、铜金与衬线标题沿用 Outerloop。
- 搜索、筛选、本机收藏、详情和 RSS 样本可用。
- 邮件流程只演示，不保存邮箱、不发邮件。Demo 通过 GitHub Pages 公开托管，RSS 仅包含已发布的 Demo 内容。

## 持续收录
每日北京时间 09:00 挖掘，最多选 1–2 项；质量不足可以零项。先核验项目官网、作者演示／论文／仓库，再去重，写入候选库。只对新增高质量项目或需要决策的情况通知。

正式版选定排版后：候选核验通过→发布到内容库→刷新站点与 RSS→进入订阅摘要。更正已有项目保留记录，避免重复推送；历史经典与近期发布分别标识。

## 收录门槛
至少一条可访问的第一手来源；有明确交互或应用新意；能用一句话说明；区分研究原型与可用产品。图像保留作者与来源，示意图明确标注。链接失效或证据不足暂存候选，不编造效果。

## 验收与待定
手机能逛；三种排版可切换；筛选和收藏可组合；没有结果时可恢复；演示邮箱不被持久化；每项能找到来源。

待用户选定：排版 A/B/C。真实订阅开放前再确定发信服务、发信域名与退订／确认实现；不承诺未经验证的自动发信。GitHub 仓库与 Pages 用于托管 Demo，正式域名下一阶段连接，Outerloop 不改动。
